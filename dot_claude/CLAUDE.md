# Global Claude Code instructions

Applies to every Claude Code session on this machine. Keep it generic — this file
is tracked in a **public** repo. Machine- or work-specific rules belong in a local,
untracked project `CLAUDE.md` instead.

## Workflow habits

- **Verify before claiming done.** Run the build/tests and show the output. "Looks
  right" is not evidence.
- **Commit only when I ask.** Never push to a default branch without confirming;
  branch first if needed.
- **Small, atomic commits** with clear messages describing the *why*, not just the *what*.
- **Scope discipline.** Change only what the task needs. Don't refactor, rename, or
  "clean up" unrelated code without asking.
- **Surface assumptions and tradeoffs** before doing non-trivial work; ask when a
  requirement is ambiguous rather than guessing.
- **Prefer the simple, boring solution.** Flag it if a request adds needless complexity.
